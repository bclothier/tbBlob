## How to build and test (read before any task)

tbBlob is a twinBASIC (tB) console EXE. **Compiling is manual in the twinBASIC IDE** (PRD req. 38; D-010). The source of truth is the `Source\` folder; `tbBlob.twinproj` is rebuilt from it.

| Step | Command / action |
|---|---|
| Rebuild the project file from `Source\` | `powershell -ExecutionPolicy Bypass -File tests\import.ps1` (created in 1.0; until then: `Build\tBImportExport_win64.exe import ".\tbBlob.twinproj" ".\Source" --overwrite`) |
| Compile | **Ask the user**: open `tbBlob.twinproj` (close/reopen if already open), platform **win64**, File → Build. Output: `Build\tbBlob_win64.exe`. Ask them to paste the IDE error list if the build fails. |
| Unit tests (`<test cmd>` for tB tasks) | `Build\tbBlob_win64.exe --self-test` — exit code 0 = all pass; each failure prints `FAIL <test name>: <detail>` |
| Integration tests | `Build\tbBlob_win64.exe --self-test --integration` (runs unit + integration tests; touches CastXML, MSVC, MSXML6, tBImportExport) |
| C fixture build + C test | `powershell -ExecutionPolicy Bypass -File tests\fixture-c\build.ps1` (created in 2.0) |
| Full suite (`<full suite cmd>`) | `powershell -ExecutionPolicy Bypass -File tests\run-all.ps1` (created in 1.0, extended by later tasks). It refuses to report on an EXE older than the newest file in `Source\` and prints which one is stale — ask the user to recompile. |

Every "Run" step that needs a fresh tB build means: run `tests\import.ps1`, ask the user to compile, wait for "built", then run the command. Tests are written in `Source\Sources\Tests_<Area>.twin` **modules** (not classes, not delegates — D-015): each has `Public Const MODULE_ID` (next free number), a `Register` sub calling `SelfTest.Add "<description>", MODULE_ID, <index>[, True for integration]`, and `Public Sub RunTest(index)` with a `Select Case` calling the private test subs; add one `Case` line to `SelfTest.Dispatch` and one call to `SelfTest.RegisterAll` per new module (pattern: `impexp.twinproj` → `SelfTest.twin`; exported reference copy: run `Build\tBImportExport_win64.exe export "tools\impexp\impexp.twinproj" "<scratch folder>"`).
